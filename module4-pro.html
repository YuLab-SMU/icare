This extended PrognosiX workflow reflects the package’s newer prognosis capabilities and supports full clinical prognostic-model development and validation. It adds competing risks, time-dependent ROC comparison, multi-time calibration, repeated cross-validation, C-index comparison, Bayesian tuning, AIC-guided selection, overall calibration, external-validation diagnostics, and deployment.

11.1 Execution Notes

This workflow is computationally intensive and uses optional packages that are checked only when their methods are requested. Verify paths, outcome definitions, prediction horizons, the output root, and dependencies before running. Keep development and validation independent throughout, report uncertainty with point estimates, and distinguish exploratory comparisons from prespecified confirmatory analyses.

11.2 Step-by-step Workflow

The workflow is divided into short stages. Each note explains the purpose, key checks, and interpretation limits. Generated plots and tables appear directly below their code chunk.

11.2.1 About this chapter

Audience. Users who already have a working PrognosiX pipeline and want the ten production extensions on top of it.

Input. Reads data/PMID37633276_DIA_plasmaproomic.xlsx (sheet Table S1B) directly.

The chapter runs end to end as one session:

  1. Environment and configuration
  2. Data preparation (move time/status to info.data)
  3. Feature selection (ONLY on training set)
  4. Algorithm benchmarking and hyperparameter tuning
  5. Core model evaluation
    • Feature stability (LASSO bootstrapping)
    • Feature ablation (drop each feature and measure C-index drop)
    • Model sensitivity (sample size and censoring rate)
  6. Decision curve analysis (DCA) and SHAP explanations (on validation set)
  7. Ten advanced extensions (all executed sequentially)
  8. Save final PrognosiX object and deploy
  9. Final report

# script, so functions INSIDE the package that call sub_dir() themselves (e.g.
