Quick guide

Try this module

  1. Enter the seven predictors, including sex. Keep the original units used in the tutorial; the app applies the saved preprocessing recipe.
  2. Select an algorithm or ensemble and click INITIATE ANALYSIS. Change the sensitivity threshold and run again to inspect the classification decision.
  3. Use GENERATE DATA PACK to download the inputs, selected model, probabilities and threshold as JSON.

Model context. Saved tutorial classifiers · 7 inputs including sex · original labels retained. The demo uses the saved tutorial objects; it does not retrain models during a browser session.
