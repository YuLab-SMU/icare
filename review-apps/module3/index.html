Quick guide

Try this module

  1. Choose a subtyping method and enter a single profile, or switch the input mode to Batch (CSV).
  2. For a batch, download the example CSV and upload it unchanged first. The first column contains unique sample IDs; the other 24 columns are the required predictors.
  3. Run the analysis, inspect the subtype table and download the results. Subtype labels belong to each method and are not interchangeable across methods.

Model context. Saved NMF, LPA and k-means models · 24 predictors · training normalization reused. The demo uses the saved tutorial objects; it does not retrain models during a browser session.
